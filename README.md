# 🎓 Campus Recruitment Portal

A full-stack Campus Recruitment Portal developed using React.js and Supabase to streamline the campus placement process through secure role-based access for students, recruiters, and administrators.
<img width="1402" height="774" alt="image" src="https://github.com/user-attachments/assets/edf7326b-76ff-48eb-a95d-a8442d56291a" />


## 🚀 Features

- Role-based authentication with Supabase Auth
- Student profile management
- Resume upload using Supabase Storage
- Student dashboard
- Modular React architecture
- Admin Dashboard (Ongoing)

## 🛠 Tech Stack

- React.js
- Vite
- JavaScript
- HTML5, CSS3
- Supabase
- PostgreSQL
- Git & GitHub
- Vercel
